# tv-photos

Photos for the **K & A** TV launcher (Samsung Tizen, Glass Home build).

This repo is deliberately separate from the website so the upload token used on
phones can only touch photos — never the deltoro.dev site code or deploy
pipeline.

## How it works

```
phone Shortcut  ──PUT──▶  photos/<timestamp>.jpg
                                │
                                ▼
                     .github/workflows/manifest.yml
                                │
                                ▼
                          photos.json   (raw.githubusercontent.com, CORS *)
                                │
                                ▼
                     the TV app reads one URL
```

- **Images** live in [`photos/`](photos/) and are served from
  `https://raw.githubusercontent.com/andrew-deltoro/tv-photos/main/photos/<file>`
  (GitHub sends `Access-Control-Allow-Origin: *`, so no Pages setup is needed).
- **`photos.json`** at the repo root is generated by the Action — never edit it
  by hand.
- The TV's manifest URL is
  `https://raw.githubusercontent.com/andrew-deltoro/tv-photos/main/photos.json`.

## Adding photos from a phone

Use the **Upload TV Photo** iOS Shortcut (see the setup notes). It uploads to
this repo and the manifest rebuilds itself within a minute.
